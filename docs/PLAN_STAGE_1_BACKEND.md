## 1.2 — Migración del esquema

`audit_log` es una tabla nueva propiedad de `iam`; `project` gana una columna.
`config/projects.go` ya tiene `MigrateProjects(conn ddl.Execer, ddlCompiler
ddl.Compiler)` que hace `ddl.New(conn, ddlCompiler).Sync(&Project{})`.

- Renombrá `MigrateProjects` a `MigrateSchema` y hacela reconciliar **ambos**
  modelos:
  ```go
  func MigrateSchema(conn ddl.Execer, ddlCompiler ddl.Compiler) error {
  	d := ddl.New(conn, ddlCompiler)
  	if err := d.Sync(&Project{}); err != nil {
  		return err
  	}
  	return d.Sync(&AuditLog{})
  }
  ```
- `grep -rn "MigrateProjects" .` debe quedar vacío salvo que aparezca como
  nombre viejo en un comentario histórico (no debería). Actualizá los 3
  llamadores: `cmd/migrate/main.go` (paso `"projects"` → `"schema"`,
  `config.MigrateProjects` → `config.MigrateSchema`), `web/server.go`, y
  cualquier `setup_test.go` de `tests/`.
- **Anti-footgun:** `ddl.Sync` reconcilia de forma aditiva (agrega la columna
  nueva). Si en este entorno `Sync` NO agrega columnas a una tabla existente,
  **pará y reportalo** — no escribas `ALTER TABLE` a mano ni borres/recrees la
  tabla.

## 1.3 — Ciclo de vida de proyectos: `config/projects.go`

El archivo ya tiene `hashProjectSecret`, `projectSecretKey`, `CreateProject`,
`VerifyProjectSecret`, `ErrProjectNotFound`. Añadí y ajustá:

```go
// GenerateClientSecret devuelve un client_secret nuevo de alta entropía. El
// prefijo lo hace reconocible en logs/1Password; el cuerpo son 30 bytes del
// CSPRNG del ecosistema en base64 url-safe. NUNCA math/rand ni nada derivado
// del tiempo.
const clientSecretPrefix = "iam_sk_"

func GenerateClientSecret() (string, error) {
	var b [30]byte
	if err := rand.Read(b[:]); err != nil { // github.com/tinywasm/crypto/rand
		return "", err
	}
	return clientSecretPrefix + base64.URLEncode(b[:]), nil
}

// RegenerateProjectSecret reemplaza el hash del secreto de projectID. El
// secreto anterior deja de validar de inmediato (no hay ventana de gracia:
// rotar es una acción deliberada). Devuelve ErrProjectNotFound si no existe.
func RegenerateProjectSecret(db *orm.DB, projectID, newPlainSecret string) error

// SetProjectActive marca projectID activo o inactivo. Un proyecto inactivo
// NO puede emitir tokens (ver VerifyProjectSecret). ErrProjectNotFound si no
// existe.
func SetProjectActive(db *orm.DB, projectID string, active bool) error

// ListProjects devuelve todos los proyectos, ordenados por created_at
// ascendente. Envoltorio de ReadAllProject(db.Query(&Project{})).
func ListProjects(db *orm.DB) (ProjectList, error)
```

- `CreateProject`: setear `Active: 1` en la fila nueva.
- `VerifyProjectSecret`: además de comparar el HMAC en tiempo constante, tras
  leer la fila: si `rows[0].Active == 0` → devolver `false, nil`
  (proyecto desactivado no valida). `Active == 1` **o cualquier otro valor**
  (incluye filas viejas sin la columna, que leen `0`… **ojo**): para no romper
  filas de producción creadas antes de esta migración, la regla es: tras
  `ddl.Sync` la columna existe con default; si tu `ddl` no aplica default a
  filas existentes, `RegenerateProjectSecret`/`SetProjectActive` no las tocó y
  leerán `0`. Para evitar el falso negativo, **`MigrateSchema` debe hacer,
  después del `Sync`, un `UPDATE project SET active = 1 WHERE active IS NULL OR
  active = 0` idempotente** vía `conn.Exec` — documentalo con un comentario
  ("las filas previas a la columna `active` se consideran activas"). Después de
  eso, `Active == 0` significa inequívocamente "desactivado a mano".
- Imports nuevos en `projects.go`: `github.com/tinywasm/crypto/rand`
  (ya está `tinywasm/crypto` en `go.mod` v0.0.25 — el subpaquete `/rand`
  existe), `github.com/tinywasm/base64` ya se usa.

## 1.4 — Listado de roles y usuarios: `config/rbacread.go` (nuevo)

`tinywasm/rbac` expone métodos para **escribir** (`CreateRole`,
`SetRoleSessionTTL`, `DeleteRole`, `AssignRole`, `RevokeRole`,
`GetUserRoles`, `GetRoleByCode`) pero **no** para listar todos los roles de un
proyecto ni los usuarios de un rol. Esos listados se hacen componiendo con los
**codecs ORM exportados** de `rbac` sobre el `*orm.DB` compartido. Esto es
composición permitida (ver `PLAN.md`, regla 1) — **no** agregues métodos a
`tinywasm/rbac`.

Este archivo **no lleva build tag**: `config/` compila para el Worker, así que
cumple la regla TinyGo.

Los tipos de proyección **`RoleView` y `RoleUser` van en `api/admin.go`** (no
en `config/`): el módulo WASM del panel los decodifica y no puede importar
`config` (arrastra `rbac`/`auth`/`orm`). `api/` es paquete hoja sin
dependencias; `config` puede importarlo sin ciclo (ya lo hace para las
constantes de ruta).

## 1.5 — Gate de acceso al panel: `config/adminaccess.go` (nuevo)

```go
package config

import (
	"github.com/tinywasm/env"
	"github.com/tinywasm/fmt"
)

// EnvAdminEmails es la variable con la lista (separada por coma) de correos
// autorizados a entrar al panel de administración. Ver docs/ARCHITECTURE.md
// §8.2 y docs/DESIGN.md §2. Sin RBAC: entrar al panel no puede depender de la
// política que el panel administra.
const EnvAdminEmails = "IAM_ADMIN_EMAILS"

// PanelAdminList lee y parsea EnvAdminEmails. Correos vacíos y espacios se
// descartan. Devuelve nil si la variable no está.
func PanelAdminList() []string {
	raw := env.Get(EnvAdminEmails)
	if raw == "" {
		return nil
	}
	parts := fmt.Split(raw, ",")
	out := make([]string, 0, len(parts))
	for i := 0; i < len(parts); i++ {
		e := fmt.TrimSpace(parts[i])
		if e != "" {
			out = append(out, e)
		}
	}
	return out
}

// IsPanelAdmin reporta si email está en list. Comparación exacta,
// case-sensitive (los correos de Google llegan normalizados en minúscula
// desde auth; la lista se configura igual).
func IsPanelAdmin(email string, list []string) bool {
	if email == "" {
		return false
	}
	for i := 0; i < len(list); i++ {
		if list[i] == email {
			return true
		}
	}
	return false
}
```

Confirmá que `tinywasm/fmt` expone `Split` y `TrimSpace` en la versión de
`go.mod` (`v0.25.7`). `Split` se usa así en el ecosistema; si el nombre real
fuera otro (`fmt.SplitString`, etc.), usá el que exista — **no** importes
`strings`.
